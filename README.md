# Хата в селі

Платформа для пошуку тихої, затишної тимчасової оселі в українських селах — для відпочинку та відновлення. Український аналог Airbnb, орієнтований на переселенців, військових та їхні родини, і всіх, хто втомився від війни.

Повний продуктовий бриф — у [`CLAUDE.md`](./CLAUDE.md).

## Ключові факти проєкту

- **Аудиторія:** переселенці, військові та їхні родини, українці, втомлені від війни.
- **Географія:** уся підконтрольна Україні територія, подалі від великих міст.
- **Платформа:** веб (десктоп + мобільна версія), мобільний застосунок — опційно.
- **Монетизація:** зараз безкоштовне демо, пізніше — комісія з власників за бронювання (цінова паритетність для гостя).
- **MVP:** пошук і фільтри (природа, регіон, кімнати, ціна), картки хатинок, онлайн-бронювання з оплатою, відгуки та рейтинги.
