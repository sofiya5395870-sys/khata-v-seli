# Хата в селі

Платформа для пошуку тихої, затишної оселі в українському селі — для душевного відпочинку, відновлення, зимівлі та життя наодинці з природою і тишею. Англійська версія — **Village House**.

Курсовий UX/UI-кейс: дванадцять кроків від дослідження ринку до передачі в розробку. Готові перші три.

Повний продуктовий бриф — у [`brief/brief.md`](./brief/brief.md).

## Як влаштований репозиторій

Два формати, один вміст:

- **`.md`** — робочі документи: міркування, джерела, таблиці, відкриті питання.
- **`.html` у корені** — та сама робота, зібрана сторінкою для показу.

| Сторінка | Що показує |
|---|---|
| [`index.html`](./index.html) | Титульна: що за проєкт і на якому він кроці |
| [`research.html`](./research.html) | Крок 1 — ресерч і бенчмарк |
| [`personas.html`](./personas.html) | Крок 2 — персони і джоби |
| [`ia.html`](./ia.html) | Крок 3 — інформаційна архітектура, потоки й критика |

Спільне для всіх сторінок лежить у [`assets/`](./assets): `nav.js` рендерить ліве меню, `sidebar.css` і `case.css` — стилі. Щоб додати крок або розділ у меню, правити треба **тільки** `assets/nav.js`.

## Ключові факти проєкту

- **Аудиторія:** пріоритетно українці, які хочуть відпочити; вимушені переселенці; військові та їхні родини; іноземці в Україні, яким треба відпочити й попрацювати без перебоїв світла та води. Наскрізний сценарій — зимівля. Бронюють соло, пари, сім'ї — не компанії.
- **Географія:** уся підконтрольна Україні територія, подалі від великих міст. Мапа — у кордонах 1991 року.
- **Гарантія платформи:** світло, вода, тепло, інтернет і парковка є в кожній оселі — інакше гість отримує 50% вартості доби від власника. Кухня є всюди, але поза компенсацією.
- **Монетизація:** зараз безкоштовне демо, пізніше — 10% комісії з власника. Знижка 5% військовим та їхнім рідним — з комісії платформи, діє на кожній оселі.
- **Оплата:** повна передоплата (Apple Pay, LiqPay, WayForPay, Stripe, картка), без застави, безкоштовне скасування за кілька днів до заселення.
- **Каталог:** близько 30 хатинок у демо.
- **MVP:** навігація за природою й регіоном, мапа, розгорнуті фільтри, окремий розділ «Зимівля», картки осель, онлайн-бронювання, відгуки без зіркових рейтингів, вішліст із можливістю поділитися, публічні критерії відбору.
- **Платформа:** веб (десктоп + мобільна версія), застосунок — опційно.
- **Результат:** hi-fi інтерактивний прототип рівня справжнього продукту — для портфоліо та LinkedIn-кейсу.

Деталі — у [`brief/brief.md`](./brief/brief.md).

## Запуск локально

Статичні файли без збірки. Щоб сторінки бачили `assets/`, відкривати через сервер, а не подвійним кліком:

```sh
python3 -m http.server 8000
```

Далі — <http://localhost:8000/index.html>.
