# Хата в селі

Платформа для пошуку тихої, затишної оселі в українському селі — для душевного відпочинку, відновлення, зимівлі та життя наодинці з природою і тишею. Англійська версія — **Village House**.

Повний продуктовий бриф — у [`CLAUDE.md`](./CLAUDE.md).

## Люди: що де лежить

| Файл | Що всередині |
|---|---|
| [`research/people.md`](./research/people.md) | Інвентаризація всього, що дослідження каже про людей: хто шукає, що рухає, чого бояться, як обирають. Сім живих постів із соцмереж із коментарями. Окремо — список того, чого ми **не** знаємо |
| [`research/personas.md`](./research/personas.md) | Чотири прото-персони. Primary — та, хто чотири роки не спить. Плюс чесний перелік сегментів, персони для яких побудувати не вийшло |
| [`research/jtbd.md`](./research/jtbd.md) | Один main job, п'ять related, по три emotional і social. JTBD-матриця: джоби × персони, з колонками «що закриває в продукті» і «хто з ринку вже закриває» |
| [`research/audit.md`](./research/audit.md) | Прискіплива перевірка персон і джобів: що підтверджено, що гіпотеза, що домислено. Найнебезпечніші припущення окремим списком |
| [`personas.html`](./personas.html) | Те саме сторінкою для показу |

**Головне в двох реченнях.** Люди їдуть не по краєвид, а по сон: «4,5 роки норм не спала» — 8 тис. вподобань. А сезонної оренди на три-чотири місяці ринок не продає взагалі: торік її просили, цього року перестали, бо відмовили.

## Ключові факти проєкту

- **Аудиторія:** пріоритетно українці, які хочуть відпочити; вимушені переселенці; військові та їхні родини; іноземці в Україні, яким треба відпочити й попрацювати без перебоїв світла та води. Наскрізний сценарій — зимівля. Бронюють соло, пари, сім'ї — не компанії.
- **Географія:** уся підконтрольна Україні територія, подалі від великих міст. Мапа — у кордонах 1991 року.
- **Гарантія платформи:** світло, вода, тепло, інтернет і парковка є в кожній оселі — інакше гість отримує 50% вартості доби від власника. Кухня є всюди, але поза компенсацією.
- **Монетизація:** зараз безкоштовне демо, пізніше — 10% комісії з власника. Знижка 5% військовим та їхнім рідним — з комісії платформи, діє на кожній оселі.
- **Оплата:** повна передоплата (Apple Pay, LiqPay, WayForPay, Stripe, картка), без застави, безкоштовне скасування за кілька днів до заселення.
- **Каталог:** близько 30 хатинок у демо.
- **MVP:** навігація за природою й регіоном, мапа, розгорнуті фільтри (камін, чан/сауна, мангал, тварини, безбар'єрність, кімнати, ціна, замовлення місцевої їжі), окремий розділ «Зимівля», картки осель, онлайн-бронювання, відгуки без зіркових рейтингів, вішліст із можливістю поділитися, публічні критерії відбору.
- **Платформа:** веб (десктоп + мобільна версія), застосунок — опційно.
- **Результат:** hi-fi інтерактивний прототип рівня справжнього продукту — для портфоліо та LinkedIn-кейсу.
