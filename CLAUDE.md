# Робота над проєктом «Хата в селі»

Курсовий UX/UI-кейс: платформа пошуку тихої оселі в українському селі. Репозиторій — публічне портфоліо, тому все в ньому читає стороння людина.

**Продуктовий бриф — у [`brief/brief.md`](./brief/brief.md).** Там аудиторія, географія, гарантія, монетизація, скоуп MVP і тон голосу. Карта всіх файлів — у [`README.md`](./README.md).

## Де що лежить

| | |
|---|---|
| `brief/brief.md` | Продуктовий бриф — джерело правди по продукту |
| `research/` | Кроки 1–2: ресерч, бенчмарк, люди, персони, джоби |
| `ia/` | Крок 3: сутності, екрани, навігація, трасування, потоки, критика |
| `*.html` у корені | Ті самі матеріали сторінкою для показу |
| `assets/` | Спільні для всіх сторінок меню і стилі |

Порожні папки — `wireframes/`, `concept/`, `tokens/`, `components/`, `design-system/`, `handoff/` — чекають на свої кроки. Не наповнювати їх наперед.

## Правила роботи

**Два формати, один вміст.** `.md` — робочий документ із міркуваннями й джерелами. `.html` у корені — та сама робота, зібрана сторінкою. Міняєш один — перевір другий.

**Меню сторінок — в одному місці.** Ліве меню рендерить `assets/nav.js`, стилі — `assets/sidebar.css`, спільна основа сторінок — `assets/case.css`. Щоб додати крок або розділ, правити треба там, а не в кожній сторінці. Сторінка лише каже, на якому вона кроці: `<body data-page="03">`.

**Кожен факт — із джерелом.** Посилання, дата перевірки, цифра. Де джерела немає — писати **«дані не підтверджені»** явно, а не замовчувати. Позначки походження описані в [`research/summary.md`](./research/summary.md), розділ «Як читати».

**Кожна сутність і кожен екран — із джобом.** Те, що не породжує жоден джоб, не викидається мовчки, а виноситься в «Під питанням» на рішення.

**Про аудиторію — дбайливо.** Серед людей, для яких це робиться, є ті, хто пережив війну й переїзд. Без лексики втечі, без ринкових одиниць на місці людей.

**Рішення по скоупу ухвалює Софія.** Пропозиції подавати як пропозиції, з підставою і компромісом, а не як готове рішення.

## Статус

Готові кроки 1–3. Наступний — прототипування і вайрфреймінг. Прогрес по всіх дванадцяти кроках — на [`index.html`](./index.html).
